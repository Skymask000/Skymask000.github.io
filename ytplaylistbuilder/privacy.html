Privacy Policy

YT Playlist Builder. Last updated: 2026-09-10.

Summary

YT Playlist Builder is a browser extension that turns a pasted list of songs into a YouTube playlist on your own YouTube account. It runs entirely in your browser and communicates only with Google's own services (Google Sign-In and the YouTube Data API v3). It has no third-party servers, no analytics, no telemetry, and does not collect, transmit or share personal data with anyone other than Google, which you are already signed in to.

Data the extension accesses

To function, the extension needs limited access to your Google account, granted through Google's OAuth 2.0 consent flow. You see Google's standard consent screen listing exactly what access is being granted, and can revoke it at any time from myaccount.google.com/permissions.

The extension uses one OAuth scope, https://www.googleapis.com/auth/youtube, and within it performs only these operations on your behalf:

  • Read the list of playlists you own, to populate the "Add to existing playlist" dropdown.
  • Read your channel name and avatar, to display which account is currently signed in.
  • Create a new playlist, only when you choose "Create new" and click to add.
  • Add videos to a playlist, only when you click to add, inserting one item per checked row.

The extension does not read your watch history, subscriptions, comments or any other YouTube data. It does not modify or delete anything you did not explicitly request through the popup. It does not read or modify data belonging to any account other than the signed-in one.

Data the extension stores

All data is stored locally in your browser using Chrome's chrome.storage.local API. Nothing is transmitted to any server other than Google's own OAuth and YouTube API endpoints.

  • OAuth access token, a short-lived credential (typically about an hour) received from Google after sign-in, cached to avoid re-prompting on every action.
  • Signed-in account identity, the YouTube channel name and avatar URL, so the popup can show which account is in use without re-fetching.
  • In-progress run state, the pasted song list, the per-song matches, the selection state of each row and the insertion progress, so a run survives closing the popup or restarting the browser and can be resumed.

You can clear all locally stored data at any time by clicking Sign out in the popup (token and identity), clicking Reset (run state), or removing the extension from chrome://extensions/ (everything).

Data the extension does not collect or transmit

  • No browsing history
  • No YouTube watch history, subscription list or comments
  • No IP addresses
  • No cookies
  • No usage analytics or telemetry
  • No crash reports
  • No personally identifiable information beyond what the OAuth flow itself involves, which is between you and Google, not the developer

Third parties

The extension makes network requests to only two categories of endpoint:

  • Google Sign-In (accounts.google.com), via chrome.identity.launchWebAuthFlow. Standard OAuth 2.0.
  • YouTube Data API v3 (www.googleapis.com/youtube/v3/*), for the operations listed above.

No requests are made to any developer-controlled server, third-party analytics service or other external system.

YouTube search results

To find candidate videos without consuming YouTube Data API quota, the extension fetches the public YouTube search results page (youtube.com/results) and parses video metadata from the returned HTML. This is a read-only, unauthenticated request. No user data is sent, and no cookies are attached beyond what the browser sends to youtube.com by default. The response is not stored or transmitted anywhere; only the parsed video IDs and titles populate the match table in the popup.

Changes to this policy

Any change will be reflected on this page with an updated date, and noted in the extension's version notes on the Chrome Web Store.

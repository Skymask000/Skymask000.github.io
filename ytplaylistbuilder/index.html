YT Playlist Builder

Turn a pasted list of songs into a YouTube playlist on your own account.

Install from the Chrome Web Store Source code Privacy policy

What it does

Paste a song list, either as Artist - Song lines or as numbered artist blocks. The extension finds a video for each entry, shows you every match in a table, and lets you untick anything it got wrong. Only then does it create the playlist, or add the songs to a playlist you already own.

How it works

  • Video search reads the public YouTube results page directly, so it uses no API quota.
  • Playlist creation and additions use the YouTube Data API on your own account, and only when you click to add.
  • Searching and adding continue in the background, so you can close the popup and come back to it.
  • Nothing is sent to any server other than Google's own. There are no analytics and no tracking.

Permissions

Signing in uses Google's standard consent screen and grants the https://www.googleapis.com/auth/youtube scope, which is what allows a playlist to be created and videos added to it. The extension reads your playlist list and channel name to show you which account you are signed into, and writes only to the playlist you selected. It never reads your watch history, subscriptions or comments, and never deletes anything. You can revoke access at any time from your Google account permissions.
